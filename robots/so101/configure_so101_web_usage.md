# SO101 Web 配置工具使用指南

## 概述

`configure_so101_web.py` 是 SO101 机器人的 Web 图形化配置工具，提供以下功能：

- **设备设置**: 配置 RynnBot 云平台连接参数
- **相机配置**: 扫描、预览和绑定前置/腕部相机
- **串口配置**: 自动检测并选择主臂/从臂的串口设备
- **机械臂标定**: 分步完成机械臂的零点校准和运动范围标定

## 启动方式

### 命令行启动

```bash
# 基本启动（自动打开浏览器）
python configure_so101_web.py
```

### 命令行参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--host` | `0.0.0.0` | 绑定的主机地址 |
| `--port` | `5001` | 绑定的端口号 |
| `--no-browser` | - | 不自动打开浏览器 |

## 配置流程

### 第一步：设备设置 (RynnBot)

配置 RynnBot 云平台连接参数，用于远程监控和控制。

**配置项：**
- **Product Key**: 产品密钥
- **Device Name**: 设备名称
- **Device Secret**: 设备密钥
- **HTTP URL**: HTTP 服务地址

**配置文件路径：** `robots/so101/config/rynnbot_config.yaml`

### 第二步：相机配置

扫描并绑定前置相机和腕部相机。

**操作步骤：**
1. 点击 **"扫描相机"** 按钮检测可用相机
2. 在相机预览卡片下方点击 **"绑定前置"** 或 **"绑定腕部"**
3. 确认两个相机都已绑定后，点击 **"保存配置"**

**配置文件路径：** `robots/so101/config/so101_config.yaml`

**相机输出键：**
- `observation.images.front`: 前置相机
- `observation.images.wrist`: 腕部相机

### 第三步：从臂串口配置

检测并选择从臂（Follower Arm）的串口设备。

**操作步骤：**
1. **拔掉** 从臂的串口设备
2. 点击 **"记录基线"** 记录当前串口列表
3. **插入** 从臂的串口设备
4. 点击 **"检测新增"** 检测新插入的设备
5. 选择检测到的串口设备
6. 点击 **"保存配置"**

**配置文件路径：** `rcp_motion/robots/so101/configs/so101.yaml`

### 第四步：从臂标定

完成从臂的零点校准和运动范围标定。

**标定流程：**

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 点击 **"连接机械臂"** | 建立与机械臂的通信连接 |
| 2 | 移动各关节到中间位置，点击 **"记录中间位置"** | 记录零点偏移 |
| 3 | 点击 **"开始记录范围"** | 开始记录运动范围 |
| 4 | 移动各关节到极限位置 | 系统自动记录最小/最大值 |
| 5 | 点击 **"结束并保存"** | 保存标定数据 |

**实时显示：**
- 关节名称、最小值、当前值、最大值
- 标定日志实时输出

### 第五步：主臂串口配置

检测并选择主臂（Leader Arm）的串口设备。操作步骤与从臂串口配置相同。

**配置文件路径：** `rcp_motion/robots/so101/configs/so101.yaml` (teleoperate.port)

### 第六步：主臂标定

完成主臂的零点校准和运动范围标定。操作步骤与从臂标定相同。

## 依赖项

- **Flask**: Web 框架
- **Flask-SocketIO**: WebSocket 支持
- **OpenCV (cv2)**: 相机捕获和图像处理
- **PySerial** (可选): 串口检测
- **PyYAML**: 配置文件读写

## 注意事项

1. **串口权限**: 在 Linux 系统上，保存串口配置时会自动尝试设置串口权限（`sudo chmod 666 <port>`）
2. **相机扫描**: 最多扫描 8 个相机索引（`/dev/video0` 到 `/dev/video7`）
3. **标定控制器**: 需要安装 `rcp_motion.robots.so101.scripts.calibrate_web` 模块
4. **浏览器兼容**: 推荐使用 Chrome 或 Firefox 浏览器

## 故障排除

### 相机无法检测
- 检查相机是否正确连接
- 确认相机设备文件存在（Linux: `/dev/video*`）
- 检查是否有其他程序占用相机

### 串口无法检测
- 确认设备已正确插入
- 检查 `ls /dev/ttyACM*` 或 `ls /dev/ttyUSB*`
- 安装 PySerial: `pip install pyserial`

### 标定失败
- 确认串口配置正确
- 检查机械臂电源是否开启
- 查看标定日志获取详细错误信息
