# TeleopPlugin 遥操插件使用手册

## 概述

`TeleopPlugin` 是 RynnRCP 的双边遥操通信插件，支持通过局域网 UDP 在**主臂（leader）**和**从臂（follower）**之间进行实时关节状态传输、摄像头图像传输、数据采集和**真机回放**。

## 架构说明

```
┌──────────────────────────────────┐       局域网 UDP
│         主臂机器（Leader）         │ ◄────────────────► │  从臂机器（Follower）  │
│                                  │                     │                       │
│  run_teleop_leader.py            │                     │  run_teleop_follower.py│
│  ├── TeleopPlugin(role="leader") │                     │  ├── TeleopPlugin      │
│  │   ├── Web UI (http://...:5001)│                     │  │   (role="follower") │
│  │   ├── 发送关节状态 → 从臂执行  │────关节状态──────►  │  │   ├── 接收并执行动作 │
│  │   ├── 接收从臂状态            │◄───从臂状态/图像─── │  │   ├── 发送状态/图像  │
│  │   └── 数据采集控制            │────采集指令────────►│  │   └── 数据采集/回放  │
│  └── RcpCore（主臂驱动）          │                     │  └── RcpCore（从臂驱动）│
└──────────────────────────────────┘                     └───────────────────────┘
```

**双方建立连接机制：**
- 双方以 1 Hz 互发心跳包。
- 只有双方均在运行，且 5 秒内互相收到心跳，数据传输才会开始。
- 任意一方下线，另一方自动停止发送业务数据。

## 快速接入

### 1. 启动从臂

```bash
cd RynnRCP/robots/wuji_tianji
python run_teleop_follower.py
```

### 2. 启动主臂（含 Web UI）

```bash
cd RynnRCP/robots/wuji_tianji
python run_teleop_leader.py
```

主臂启动后浏览器将自动打开控制面板，访问地址：

```
http://127.0.0.1:5001
```

> 若主臂和从臂在不同机器上，请修改 `config/teleop_config.yaml` 中的 IP 地址。

## 配置文件

### `config/teleop_config.yaml`

```yaml
teleop:
  leader_host: 127.0.0.1    # 主臂机器 IP（若在同一台机器则为 127.0.0.1）
  follower_host: 127.0.0.1  # 从臂机器 IP

  leader_port: 9101           # 主臂监听端口
  follower_port: 9102         # 从臂监听端口

  control_hz: 30              # 关节状态发送频率（Hz）
  image_hz: 10                # 摄像头图像发送频率（Hz）
```

> **多机部署：** 将 `127.0.0.1` 替换为对应机器在局域网中的 IP 地址。

### Python 启动代码

**主臂端：**

```python
from comm_plugin.teleop_plugin import TeleopPlugin
from rynnrcp import RynnRCP, RcpCore

teleop = TeleopPlugin(
    config_file="./config/teleop_config.yaml",
    role="leader",
    enable_web_ui=True,    # 启用 Web UI
    web_port=5001,         # Web UI 端口
    open_browser=True,     # 自动打开浏览器
)

app = RynnRCP(
    rcp_core=RcpCore(config_file="./config/so101_leader_config.yaml"),
    plugins=[teleop],
)
app.start()
```

**从臂端：**

```python
from rynnrcp import RynnRCP, RcpCore, TeleopPlugin

app = RynnRCP(
    rcp_core=RcpCore(config_file="./config/so101_config.yaml"),
    plugins=[
        TeleopPlugin(config_file="./config/teleop_config.yaml", role="follower"),
    ],
)
app.start()
```

## Web UI 使用指南

访问 `http://127.0.0.1:5001`，界面包含以下区域：

### 遥操控制区

| 按钮 | 功能 |
|------|------|
| **开始遥操** | 开始向从臂发送主臂关节状态 |
| **停止遥操** | 停止关节状态发送（从臂停在当前位置） |
| **退出** | 关闭整个应用 |

**典型遥操流程：**
1. 确认"从臂在线"状态显示绿色
2. 点击 **开始遥操**
3. 操作主臂，从臂同步跟随
4. 点击 **停止遥操** 结束

---

### 数据采集区

**采集前配置：**
- **数采批次 ID**：同一批采集数据的分组标识（默认自动生成）
- **任务名称**：episode 的文件夹名，如 `pick_and_place`
- **采集频率**：帧率（Hz），建议 30 Hz
- **采集项目**：勾选需要采集的数据键
  - `observation.state`：从臂关节角度
  - `observation.images.front`：正面摄像头图像
  - `observation.images.wrist`：腕部摄像头图像
  - `action`：执行的动作

**采集流程：**
1. 先**开始遥操**
2. 配置好任务名称和采集项
3. 点击 **开始录制** → 执行演示动作 → 点击 **停止录制**
4. 重复上述步骤采集多条 episode
5. 点击 **丢弃最近一条**（如果这条数据不好）

## 数据管理功能

点击 **🔄 刷新列表** 加载从臂机器上的本地数据，包含：
- 各数采批次下的 episode 列表
- 每条 episode 的状态、帧数

### Episode 状态说明

| 状态 | 含义 | 可操作 |
|------|------|--------|
| **完整** (complete) | 已编码：含 `timeseries.parquet` + 视频文件 | 导出、回放 |
| **未完成** (incomplete) | 原始格式：含 `streams/` 目录（npz/bin） | 编码、回放 |
| **无效** (invalid) | 格式错误或数据损坏 | 仅删除 |

### 批量操作

| 按钮 | 功能 | 说明 |
|------|------|------|
| **🔧 编码选中** | 将原始格式转换为标准格式 | 仅对"未完成"状态生效 |
| **📦 导出选中** | 打包为 ZIP，保存到从臂本地 | 支持原始和已编码格式 |

### 单条操作

每条 episode 右侧有操作按钮：

| 按钮 | 状态要求 | 功能 |
|------|----------|------|
| **▶ 回放** | 完整 / 未完成 | 在真实机器人上回放该 episode |
| **编码** | 未完成 | 单条编码（转换为标准格式） |
| **导出** | 完整 | 单条导出为 ZIP |
| **删除** | 任意 | 删除该 episode 目录 |

## 真机回放功能

回放功能允许在**真实机器人**上重现已采集的 episode 动作序列。

### 使用前提

1. 从臂机器人已连接（Web UI 显示"从臂在线"）
2. **遥操必须处于停止状态**（回放与遥操互斥）
3. 机械臂周围无障碍物

### 回放流程

**第一步：停止遥操**  
如果遥操正在运行，点击 **停止遥操**。

**第二步：点击回放按钮**  
在 Data Management 中选择目标 episode，点击 **▶ 回放** 按钮。

**第三步：确认安全提示**  
弹出确认对话框，确认机械臂周围无障碍物后点击确定。

**第四步：观察进度**  
回放进度面板实时显示：

```
▶ 真机回放中...                          episode_000001
移动到起始位置...                              12%
[████████░░░░░░░░░░░░░░░░░░░░░░░░░░░░░]
                                  [⏹ 停止回放]
```

**第五步：回放完成**  
进度达到 100% 后自动结束，进度面板消失。

### 进度阶段说明

| 进度 | 阶段 | 描述 |
|------|------|------|
| 0% | 加载数据 | 从磁盘加载 episode 的 action 序列 |
| 0% → 50% | **预移动** | 机械臂从当前位置线性插值到 episode 第一帧位置（约 3 秒） |
| 50% → 60% | **等待** | 机械臂停在起始位置保持 2 秒，倒计时显示 |
| 60% → 100% | **回放** | 按原始采集时间戳逐帧执行 action |

### 中途停止回放

点击进度面板中的 **⏹ 停止回放** 按钮，机械臂立即停止在当前位置。

### 支持的数据格式

| 格式 | 文件结构 | 状态显示 |
|------|----------|----------|
| **编码格式** | `timeseries.parquet` + `*.mp4` 视频 | 完整 |
| **原始格式** | `streams/action.npz` + `streams/state.npz` | 未完成 |

两种格式均支持回放，插件自动识别格式并加载。

### 时间戳驱动执行

回放时严格按照原始采集时间戳执行 action，而非固定帧率：
- 高帧率采集（如 60Hz）：按实际时间间隔执行，不会过快
- 帧率波动：自动适应原始采集节奏
- 保证回放与采集在时间轴上完全一致

## 消息类型说明

插件内部消息使用分段编号，便于扩展：

| 编号范围 | 类别 | 说明 |
|----------|------|------|
| 100–199 | 核心数据 | 图像、关节状态、动作等 |
| 200–299 | 数据采集控制 | 开始/停止录制、导出等 |
| 300–399 | 数据管理 | 扫描、删除、导出、编码 |
| 400–499 | 回放控制 | 开始/停止回放 |
| 500–599 | 状态/心跳 | 录制状态、心跳、导出进度 |
| 600–699 | 回放状态 | 回放进度上报 |
| 700–799 | 数据管理响应 | 扫描/删除/导出结果 |

## 常见问题

### Q: 从臂在线状态一直显示"离线"？

**A:** 检查以下几点：
1. 确认从臂脚本已启动
2. 检查 `teleop_config.yaml` 中的 IP 和端口是否正确
3. 确认防火墙未阻止 UDP 9101/9102 端口
4. 若在同一台机器上测试，`leader_host` 和 `follower_host` 均填 `127.0.0.1`

---

### Q: 回放按钮点击后提示"请先停止遥操"？

**A:** 回放与遥操互斥，必须先点击 **停止遥操**，再使用回放功能。

---

### Q: 原始格式（未完成）的 episode 能直接回放吗？

**A:** 可以。回放功能直接读取 `streams/action.npz` 和 `streams/observation.state.npz`，无需先编码。但建议先**编码**后再回放，以便验证数据完整性。

---

### Q: 数据存储在哪里？

**A:** 所有数据存储在从臂机器的：
```
~/.cache/RynnRCPData/data_coll/<数采批次ID>/<任务名称>/episode_XXXXXX/
```

导出的 ZIP 文件保存在：
```
~/.cache/RynnRCPData/data_coll/export_dir/
```

---

### Q: 如何在不同网络下使用？

**A:** 修改 `config/teleop_config.yaml`：
```yaml
teleop:
  leader_host: 192.168.1.100    # 主臂机器的局域网 IP
  follower_host: 192.168.1.200  # 从臂机器的局域网 IP
  leader_port: 9101
  follower_port: 9102
```
确保两台机器在同一局域网内，且防火墙开放对应 UDP 端口。
